# AI Career Copilot · 竞品分析

> 文档状态：初稿 ｜ 更新日期：2026-08-28 ｜ 作者：ZBC666
> 用途：明确差异化定位，为 PRD（第 3 步）的功能取舍与产品策略提供依据。

---

## 一、分析目的与方法

### 1.1 目的

1. 摸清"AI 求职辅助"赛道的现有玩家、功能边界与商业模式
2. 找到 AI Career Copilot 的差异化切入点和空白机会
3. 为 MVP 的"做什么 / 不做什么"提供决策依据

### 1.2 方法

- 按**功能形态**将竞品分三类：简历工具 / 面试工具 / 求职全流程管理
- 对国内 + 海外代表性产品做功能、AI 能力、商业模式拆解
- 输出横向对比 + 核心洞察

## 三、国内竞品详情

### 3.1 多面鹅 / 鹅来面（OfferGoose）—— 最强对标

- **定位**：AI 面试模拟 + 实时面试助手 + 简历优化 + 深度复盘
- **核心能力**：
  - AI 模拟面试：1v1，可选角色/难度/音色，实时语音识别（ASR，准确率约 95%）
  - 实时面试提醒：面试中 ASR 转写 → 推送 STAR 结构化答题框架（用 CoT 推理，不替用户作答）
  - 简历优化：一键抓取招聘网站 JD → 三层关键词解码（硬性要求 / 差异化 / 隐性期望）→ 匹配评分 → 智能提问引导回忆真实细节 → 针对性改写
  - 智能押题：基于 JD 与企业面经库生成预测题库
  - 深度复盘：面试后多维度评估报告
- **商业模式**：订阅制 + 免费额度
- **优缺点**：追问逻辑强、复盘细致；但**核心在"面试"单点，缺乏求职数据闭环与投递漏斗分析**，且偏工具而非"决策助手"

### 3.2 速创猫 / 闪光简历

- **定位**：AI 简历生成 + 优化 + 模拟面试 + 职业规划的一站式简历平台
- **核心能力**：简历生成、按岗位定制、模拟面试
- **特点**：面向应届生/转行者，十分钟出简历；本质仍是"简历工具"，决策与复盘能力弱

### 3.3 百度网盘 AI 求职 / 智联 AI 求职教练

- 百度网盘：依托云存储生态，简历处理 + 证件照 + 模拟面试
- 智联：绑定招聘账号，简历优化 + 面试模拟 + 职业规划
- **特点**：巨头生态位产品，功能覆盖广但深度一般，且绑定各自平台

## 四、海外竞品详情

### 4.1 Teal —— 求职全流程管理标杆

- **定位**：一站式求职管理平台（4M+ 用户）
- **核心能力**：
  - 求职看板（Job Tracker）：kanban 管理所有投递，状态/备注/跟进提醒
  - Chrome 插件：从 LinkedIn/Indeed 等 40+ 招聘网站一键保存岗位
  - 简历构建器：AI 生成要点、JD 关键词匹配评分、ATS 优化
  - 匹配器：简历 vs JD 对比 → 匹配分 + 缺失硬/软技能识别 + AI 补关键词
  - 求职信/LinkedIn 简介生成
- **商业模式**：Freemium。免费版含无限简历 + 无限职位追踪；Teal+ $13/周 或 $29/月 或 $79/季
- **优缺点**：**求职管理体验业界最强**；但面向海外求职市场，不支持中国校招（如网申、笔试、应届身份等场景），定价偏高

### 4.2 Rezi

- **定位**：ATS 优先的 AI 简历生成器
- **核心能力**：AI 自动生成 ATS 友好简历、按目标岗位定制、面试题自动化定制
- **特点**：专注简历生成单点，无求职管理

### 4.3 Final Round AI / JobWhiz / InterviewAI

- **定位**：AI 面试模拟/实时辅助
- **能力**：个性化模拟面试、实时反馈、评分、辅导提示
- **特点**：面试单点能力，价格区间 $25~150/月 不等

## 六、核心洞察与差异化机会

### 6.1 市场侧洞察

1. **赛道已被验证**：52% 求职者已尝试 AI 辅助求职（智联调研），市场教育完成，用户接受度高
2. **国内竞品重"面试/简历"单点，轻"数据闭环"**：几乎无人做"投递→面试→Offer 漏斗分析 + 行为复盘"
3. **海外强产品（Teal）未适配中国市场**：中国校招有网申、笔试、应届身份、企业人才库等独特流程，存在本地化空白
4. **"可解释"是差异化**：现有产品多数只给一个匹配百分比，用户依然不知道"差在哪、怎么改"

### 6.2 AI Career Copilot 的差异化定位

> **一句话定位**：面向中国应届生的、以"可解释匹配 + 数据复盘"为核心的 AI 求职决策与面试助手。

三大差异化支柱：
1. **可解释的匹配决策**：不是"一个百分比"，而是"岗位要求 → 你的强项/短板/Gap → 怎么做"的完整推理链路
2. **RAG 求职知识库**：把求职方法论沉淀为可检索、可引用的知识（国内竞品缺失）
3. **数据闭环 + AI 评测**：投递漏斗 + 面试复盘 + Evaluation 体系，证明"我在用数据做决策"——这也是面向 AI 产品岗作品集的核心叙事

### 6.3 明确"不做"（MVP 边界）

- 不做招聘信息聚合/爬虫（合规与成本高）
- 不做企业侧 HR 工具（目标用户是求职者）
- 不做实时面试作弊辅助（伦理问题，且与"训练/提升"定位冲突）
- 不做多语言/海外求职（聚焦中国市场）

## 七、对产品决策的启示（输入 PRD）

| 竞品事实 | 对本项目的启示 |
|---|---|
| Teal 证明"求职管理"有需求 | MVP 包含投递管理 + Dashboard 漏斗 |
| 多面鹅证明"AI 面试"有付费意愿 | AI 面试 + 评分复盘为 P0 |
| 国内无"知识库 + 可解释匹配"组合 | 该组合即差异化核心，重点打磨 |
| 竞品多"只给分数不讲原因" | 匹配结果必须可解释、可溯源 |
