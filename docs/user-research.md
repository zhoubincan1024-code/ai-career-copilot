## 一、研究概述

### 1.1 研究背景

2026 届高校毕业生规模达 **1270 万**，同比增加 48 万，连续 8 年突破千万，就业市场竞争持续加剧（来源：教育部统计，转引自学职平台/央广网）。"投了很多简历没有回音"成为应届生求职最普遍的困境。

### 1.2 研究目标

1. 验证"应届生求职决策难"这一核心问题是否真实存在、有多大
2. 找出求职过程中**最痛、最频繁、影响最大**的环节
3. 为产品 MVP 功能取舍提供优先级依据
4. 沉淀可面试讲解的"真实用户问题"

### 1.3 研究方法

| 方法 | 说明 | 状态 |
|---|---|---|
| 桌面调研 | 2026 就业数据、求职痛点公开报道、行业报告 | 已完成 |
| 竞品桌面分析 | 国内/海外 AI 求职工具盘点 | 见《竞品分析》文档 |
| 深度用户访谈 | 5～10 名应届生/初阶求职者半结构化访谈 | 待执行（使用文末提纲） |
| 问卷验证 | 面向目标用户群的小样本问卷（30+ 份） | 待执行 |

## 二、宏观就业环境（2026）

| 事实 | 数据 | 含义 |
|---|---|---|
| 毕业生规模 | 1270 万，同比 +48 万 | 供给端压力持续增大，竞争加剧 |
| 简历投递效率 | 本科生平均投 **46 份**简历才获得 1 次面试 | 投递量 ≠ 反馈率，反馈率极低 |
| 求职周期 | 整体拉长到 **3.5 个月**左右 | 决策与焦虑时间被拉长 |
| AI 初筛 | 双非文科生简历 AI 初筛通过率仅 **13.5%** | 简历可能在到 HR 眼前前就被机器筛掉 |
| 企业 AI 化 | 超 60% 企业已使用 AI 筛选简历（ATS） | 关键词匹配成为硬门槛 |
| 结构性矛盾 | 专业/技能结构与岗位要求失配 | "不会选方向"是普遍问题 |

来源：教育部统计数据（学职平台、央广网）；麦可思研究院《2026 年大学生就业报告》（转引自网易新闻）；ATS 筛选相关报道（搜狐）。

## 三、目标用户画像

### 3.1 目标用户分层

| 用户群 | 特征 | 优先级 | 说明 |
|---|---|---|---|
| **核心用户**：2026/2027 届应届生（本科为主） | 有明确就业压力；缺乏职场经验与求职方法论；对 AI 工具接受度高 | P0 | 本项目主战场 |
| 次级用户：2 年内择业期未就业者 | 身份焦虑更强（应届身份过期）；需要兜底方案 | P1 | 与核心用户高度重叠 |
| 潜在用户：实习/考研转就业人群 | 需要快速补足求职能力 | P2 | 后期可覆盖 |

### 3.2 用户画像（Persona）

**画像 A · "海投焦虑型"小周（22 岁，应届本科生）**
- 状态：投了 60+ 份简历，仅收到零星回复，怀疑自己能力不行
- 行为：一份简历走天下；熬夜刷招聘 App；收藏一堆求职攻略但用不上
- 情绪：焦虑、自我怀疑、挫败感强
- 核心诉求：**"我到底该投什么？我的简历到底差在哪？"**

**画像 B · "目标模糊型"小李（21 岁，大四在读）**
- 状态：不知道自己适合什么岗位；专业与兴趣不一致
- 行为：从众投递热门岗位；面试被问到"为什么选这个岗"时答不上来
- 情绪：迷茫、害怕选错方向
- 核心诉求：**"帮我找到适合我的方向，并告诉我怎么准备。"**

**画像 C · "面试受挫型"小陈（23 岁，往届生）**
- 状态：有实习经历但面试总挂；不懂复盘，同一错误反复犯
- 行为：背题、看面经，但缺乏针对性训练
- 情绪：越挫越丧，对面试有心理阴影
- 核心诉求：**"让我有针对性地练面试，并且告诉我差在哪、怎么改。"**

## 四、核心痛点清单（按严重度排序）

综合桌面调研与公开报告，应届生求职过程中的核心痛点如下：

| # | 痛点 | 证据/表现 | 严重度 | 阶段 |
|---|---|---|---|---|
| P1 | **投递无回音，反馈黑洞** | 投 50~150 份无回复是普遍现象；46 份才 1 次面试 | ★★★★★ | 投递 |
| P2 | **简历与岗位 JD 匹配度低** | 一份简历投所有岗；ATS 关键词匹配不过关，初筛通过率仅 13.5% | ★★★★★ | 投递前 |
| P3 | **不知道适合什么岗位（定位模糊）** | 近七成应届生/初阶职场人"个人定位模糊"；职业规划不清晰占 49.2% | ★★★★☆ | 求职起点 |
| P4 | **简历写不好（表达与结构）** | 简历制作是主要挑战环节（56.9%）；只会写"做了什么"不会写"做成了什么" | ★★★★☆ | 投递前 |
| P5 | **面试表现差（紧张/表达）** | 面试太紧张 49.95%、表达沟通欠缺 49.46%；自我介绍薄弱 40.9% | ★★★★☆ | 面试 |
| P6 | **不会复盘，重复犯错** | 面试后无系统复盘，同样问题下次再挂 | ★★★☆☆ | 面试后 |
| P7 | **投递过程管理混乱** | 岗位版本乱、进度靠 Excel 硬记、错过跟进时机 | ★★★☆☆ | 全流程 |
| P8 | **Offer 选择纠结** | 职业目标不清晰导致决策困难，怕选错 | ★★★☆☆ | 收尾 |

来源：智联招聘《2026 职场人求职盲区调研报告》；光明网求职调查；简历筛选相关报道（搜狐、牛客网）。

## 五、用户旅程与情绪曲线

```
认识自己 → 找岗位 → 改简历 → 投递 → 面试 → 复盘 → 决策
  [迷茫]    [海量]   [无助]   [无回音]  [紧张]  [无方法]  [纠结]
```

- **最高焦虑点**：投递后无回音（漫长的等待 + 零反馈）
- **最高挫败点**：简历被拒且不知道为什么（"我明明很优秀"）
- **最大信息缺口**：缺少"以终为始"的目标岗位反向指导

## 六、机会点推导（痛点 → 产品机会）

| 痛点 | 产品机会 | 对应 MVP 功能 | 优先级 |
|---|---|---|---|
| P3 定位模糊 | 用 JD 反推岗位画像，帮用户"知道自己该投什么" | JD 解析 + 岗位匹配 | P0 |
| P2/P4 简历不匹配 | 解析 JD 要求 → 与简历逐项对比 → 给出差距与改写建议 | Resume Gap Analysis + AI 简历优化 | P0 |
| P5 面试差 | 基于目标岗位的 1v1 AI 模拟面试 + 结构化评分 | AI 模拟面试 + 评分复盘 | P0 |
| P6 不会复盘 | 面试记录留存 + 结构化复盘报告 | 面试复盘（Interview 模块） | P0 |
| P1 反馈黑洞 | 提供可解释的匹配结果（不只是百分比），让"被拒"变"可改进" | 匹配结果可解释化 | P0 |
| P7 管理混乱 | 投递状态看板 + 漏斗分析 | 投递管理 + Analytics | P1 |
| 知识分散 | 沉淀求职方法论资料，边用边学 | RAG 求职知识库 | P1 |
| P8 Offer 纠结 | 用数据帮用户理性对比多个 offer | AI 求职规划 | P2 |

## 八、用户访谈提纲（供后续执行）

1. 你目前在找工作吗？进行到哪个阶段了？
2. 你投过多少份简历？有回复的比例大概多少？
3. 你投简历前会为每个岗位单独改简历吗？为什么/为什么不？
4. 收到"已读不回"时，你一般怎么想？你清楚自己被拒的原因吗？
5. 你准备过面试吗？怎么准备的？效果如何？
6. 面试后你会复盘吗？通常怎么复盘？
7. 你用过 AI 求职工具吗？觉得有用/没用在哪？
8. 如果把简历/JD 交给 AI 分析，你最担心什么？
9. 你希望一个求职助手在哪个环节最帮你？排序题。
