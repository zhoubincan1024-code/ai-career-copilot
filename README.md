# AI Career Copilot

> 面向应届生的 AI 求职决策与面试助手（个人作品集主项目）

## 项目定位

本项目目标岗位：**AI 产品经理 / AI 产品运营**。

核心不是"AI 帮你找工作"，而是用**真实求职问题**证明一套完整能力闭环：

发现问题 → 用户研究 → 产品设计 → AI 方案 → 开发 → Evaluation → 数据分析 → 迭代

## 核心功能（规划）

- JD 解析 + 岗位匹配（Match Score + Gap Analysis）
- 简历结构化解析 + AI 简历优化
- AI 模拟面试 + 结构化评分
- RAG 求职知识库（pgvector 检索 + 来源引用）
- 投递管理与求职数据分析

## 技术栈（规划）

- Frontend：Next.js / React + Tailwind CSS
- Backend：FastAPI + Pydantic
- AI：LLM API + Structured Output + Prompt Versioning
- Data：PostgreSQL + pgvector + Redis
- Deploy：Docker Compose
